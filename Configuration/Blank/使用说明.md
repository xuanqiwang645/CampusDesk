# CampusDesk 空白配置模板

适用于 v2.0.2 Tarantula 及以后版本。模板不含个人学校地址、登录资料、API 密钥、账户标识或学习数据。

直接使用安装包时，在 CampusDesk「连接与设置」中填写学校网址；在「学习助手」中配置 DeepSeek 密钥。密钥保存到本机钥匙串，不写入本模板。现有用户使用升级补丁即可保留原有配置，无需导入空白文件。

自行构建源码时，将 SchoolConfig.json 和 MicrosoftGraphConfig.json 放入源码的 Resources 目录。学校网址必须是学校实际使用的 HTTPS 地址；不使用的平台保留空字符串。Microsoft Graph 是可选连接方式，不使用时保留 clientId 为空，tenant 为 organizations；使用时填写你自行注册的公开客户端 ID，无需客户端密钥。修改后重新构建。

这两份文件只配置学校入口和可选的 Graph 公开客户端，不是数据备份，也没有清空或迁移资料的功能。请勿把学校密码、DeepSeek 密钥、Cookie、令牌或现有用户数据填入公开文件。

## 已内置的 API 归纳限制

- 所有 AI 生成待办都复核原文学业行动；选课、注册检查、行政通知和活动不能仅凭“homework”标签进入作业。
- 课堂准备必须有适用日期；today／tomorrow 以原帖发表日为基准。没有明确截止、发表日不明或已超过 14 天的旧内容留在消息页核对。正式学校作业、个人任务及明确绝对截止的真正逾期作业保留。
- 使用软件提供的当前时间，按北京时间核对活动日期，不能把抓取日期当活动日期。
- 活动需要完整、可解析的日期，以及原文中的强制参加或已报名／已确认参加证据。普通邀请、日期或年份不明的活动留在消息页核对。
- 已结束的自动归纳活动不进入当前待办、小组件和 AI 提醒。真正未完成的逾期作业继续保留。
- 同一账号、相同原文和行动证据、相同日期的重复活动合并展示，完成标记关联所有重复编号。
- 原始消息、已保存分析及人工记录保留；用户明确的人工分类和截止时间纠正优先。

这些限制由软件执行，不能通过编辑本模板放宽。此文件是说明，不是可执行提示词。

「连接与设置 → Teams 自动整理 → 按新规则重审受限分析」可重新发送受限内容给 DeepSeek，按 API 账户计费；重审保留原分析、任务编号和完成标记，结果仍需通过本地核验。
