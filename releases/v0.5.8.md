# CampusDesk 0.5.8

- 重做成绩目标模拟与学期 GPA 预测，两个面板共用按课程、学期隔离保存的类别权重与预测分数。
- 移除旧的默认剩余 30% 假设。显示类别当前均分、权重、保持／预测方式、目标所需加权均分及公式。
- 已评分不代表类别已完成；“保持当前均分”只是假设，可切换到预测。未评分类别不是零分。
- 支持粘贴 Task Category Averages 表格，或在本机补充类别；手动数据明确标注，不更改学校成绩。权重必须合计 100%。
- 日期只显示日历进度，不再阻止类别预测。支持 YYYY-MM-DD 与 YYYYMMDD，保留输入草稿。
- 预测逐门列出覆盖范围及缺失原因；参考 GPA 为纳入课程等权结果，不包含学分、AP 加权，不是官方 GPA。
- 扩展 Task Information 信息图标识别，重试不会反复关闭已打开的弹窗；仍需在真实学校页面确认同步覆盖范围。
- 适配实际 Details 面板的 h6 标题与非表格布局，支持带括号的类别名（如小组研究项目），按每门课读取自己的权重，不共用模板。

## K 线悬停

- 按收盘折线连续吸附，横竖十字线与 GPA 数值一致，不吸附日期刻度或显示日期浮标。
- 悬停值保留两位小数，交点高亮，浮标在图表边缘自动避让。
- 空白日期区域及副图不显示 GPA 浮标；离开、拖动、滚动和窗口失焦时清除悬停。
- 修复同步刷新、时间分度切换后浮标丢失的问题，保持平移时柱宽不变。

## 下载与安装

下载 **CampusDesk-0.5.8-macOS-arm64.zip**（Apple Silicon / M 系列 Mac，macOS 12 或更新版本），解压后退出旧版，将 CampusDesk.app 放入用户主目录的 Applications 文件夹并替换旧版。无需安装 Xcode 或编译工具。学习数据与学校配置独立存储，替换应用不会清除它们。

应用使用临时签名，没有 Apple Developer ID 公证。首次打开可能被 macOS 阻止；仅在确认信任本项目后，通过“系统设置 → 隐私与安全性”允许打开。不要关闭系统整体安全防护。

此安装包仅面向 Apple Silicon；Intel Mac 用户可从源码构建。
