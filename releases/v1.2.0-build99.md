# CampusDesk Theme Edition v1.2.0 Lagoon · Build 99

Teams 信息先分析再进入待办，分为作业与活动两类；同时加入可调间隔的 AI 任务提醒。应用版本保持 **1.2.0 Lagoon**，构建号为 **99**，发布标签为 `v1.2.0-build99`。

## Teams 自动整理

修复仅凭 HOMEWORK 频道名或作业关键词，就把门户故障、致谢、无作业通知等内容直接放入待办的问题。

- 开启后，已抓取的 Teams 消息正文、作业信息、反馈及已解析的附件文字交给 DeepSeek 归纳。原始抓取独立保存，AI 请求失败不会丢失原文。
- 只有确认需要行动的内容生成「作业待办」或「活动待办」。普通通知、待分析、失败和待确认的信息保留在消息页。
- 同一条消息可包含多项作业或活动；消息页显示摘要，支持人工改分类、恢复自动分类和重试。
- 内容不变时复用分析结果，消息修改或附件正文更新后重新分析。长内容分段处理，全部完成后再归纳，分段结果不会提前进入待办。
- AI 生成的任务须附有可核对的原文证据。截止时间从原始资料解析，不采纳模型臆造的日期或链接。
- 首页、待办、行事历、小组件和截止提醒使用同一份筛选结果。保留个人完成标记与备份数据。

「Teams 自动整理」位于「连接与设置」，独立于学习助手聊天的资料勾选范围，公开版默认关闭。开启会向 DeepSeek 发送上述内容并产生 API 用量，复用已保存的 DeepSeek API Key；不发送浏览器登录凭据。关闭后停止新的分析，原始消息和已有分析缓存保留。正式作业卡片仍可显示，旧的频道关键词误判不会重新变成作业。

## 定时任务提醒

主要入口位于「总览／今日概览」标题右侧、面板样式旁。鲜明的「AI 任务提醒」面板提供开关、每 **1～10 小时**的间隔、立即分析和下次时间；最近优先任务及理由也直接显示在此，点击可查看详情。连接与设置保留完整报告。默认关闭，默认间隔为两小时。

- 使用当前未完成的作业与活动待办，推荐最多三项优先事项，并保存本次摘要。
- 只提出建议，不修改任务内容或完成状态；请求期间已完成或发生变化的任务不会被过期结果再次提醒。
- 经系统通知授权后发送提醒；未授权时仍可在应用内查看分析结果。
- 应用运行期间生效，退出应用后不运行。休眠、离线或学习助手繁忙时不会补发多轮通知；没有未完成待办时不调用 API。
- 该功能独立启停，同样使用 DeepSeek API Key 并产生 API 用量。
- Teams 大批历史信息正在整理时，手动或到期的任务分析会在当前请求结束后优先执行；聊天与后台分析仍互斥。

## 深色界面

修正学习中心计划条、序号、拖动柄和主次文字，移除侧栏图标的亮色边框。统一搜索、附件、专注、成绩目标、表单、弹窗与总览课程列表的深色背景和文字。总览提醒面板在窄窗口中独占整行，保留完整控制与建议。
