# CampusDesk Theme Edition v1.1.0 Super Orion · Build 55

本次发布针对主题版 macOS（Apple Silicon，最低 macOS 12），并将构建所需源码与测试纳入仓库。

## 更新内容

- 设置向导按应用版本记录首次介绍状态：升级版本后展示一次新版介绍，不会每次启动都重播；兼容旧版完成状态。
- “继续向导”和“从头开始”使用独立的序号事件触发，连续操作也能重新创建向导流程。
- 学校平台读取失败按认证、跳转、页面无数据、网络连接、TLS 等类型显示具体原因，并保留已有缓存。
- 同步英语界面的失败提示，并扩充对应回归测试。

## 安装与安全

打开 DMG 后，将 **CampusDesk Theme Edition.app** 拖到 `~/Applications`（或 `/Applications`），更新时替换同一主题版应用即可。此版与原版 CampusDesk 使用不同的应用标识，可并存。本机数据目录不会随安装包上传或覆盖。

应用用本机持久签名，但没有 Apple Developer ID 公证。请通过 macOS 自身的安全提示审核后再打开；不要关闭 Gatekeeper。

安装包不包含 API 密钥、学校网址、登录会话、同步缓存或个人任务。源码构建命令：

```sh
CAMPUSDESK_INFO_PLIST="$PWD/Info-ThemeEdition.plist" bash build.sh
```
