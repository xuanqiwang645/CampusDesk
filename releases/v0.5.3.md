# CampusDesk 0.5.3

## Liquid Glass UI

- Added a board-only layered glass surface inspired by Apple’s Landmarks Liquid Glass sample.
- Added background extension-style ambient lighting, edge highlights, grouped dashboard surfaces, and lightweight hover feedback.
- Added a reduced-transparency fallback for macOS accessibility preferences.
- Preserved the classic dashboard, Chinese default language, English switch, source grouping, and all captured school content.
- Kept the UI dependency-free for the existing WKWebView shell; no Apple sample source was copied into CampusDesk.
