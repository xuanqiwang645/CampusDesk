# CampusDesk v2.0.1 Tarantula · Build 103

2026-11-13 · Apple Silicon macOS 12 或更新版本。

本修复版集中解决课程显示不全、Teams 通知误入待办和定时提醒使用过期任务的问题，取代 v2.0.0 的下载入口。保留现有学习数据、完成记录、登录资料及用户设置；普通版和主题版均提供完整安装包和通用原位升级补丁。

## 课程发现与成绩显示

- 修复课程根链接未进入 Tasks 页、折叠侧栏课程遗漏及部分成绩／报告入口无法进入读取队列的问题。单科加载或结构识别失败时继续读取其他课程，不将部分成功当作全部完成。
- 目录课程即使尚未读取到总评也保留显示。成绩页分别显示已发现课程数与计入 GPA 的课程数，提示缺少总评的课程，并保留原页面入口供补读。
- 按课程 ID 合并，实测课程页优先于目录占位；旧页面不覆盖新名称或 GPA 资格。新学期尚未出分时不再回退显示上学期成绩，未知学期或缺失成绩不计入 GPA，也不计为零分。
- Windows 同步在空页重试失败或达到页数上限时明确显示失败或部分读取，不提高既有读取上限。

## Teams 分类与任务记录

- 修复一条消息包含多项行动时，AI 调整顺序或插入新行动导致旧完成标记、人工截止时间匹配到另一任务的问题。先匹配原动作身份；要求不同的同名任务不复用旧标记，重复动作合并展示。
- 缺少原帖的旧启发式通知不再自动进入作业待办，原文及已有记录仍保留。频道名和发布时间不能单独作为作业或截止日期证据；不符合证据规则的旧分析留在消息页待核对。
- 保留先经 DeepSeek 分析，再区分作业、活动和普通通知的流程，以及人工纠错、附件全文分段和内容变化后重新分析。分析失败与备份恢复保留已有动作身份和完成记录。

## 定时提醒

- 在重试和下一批分析前复核当前任务，任务完成或内容变化后停止旧请求，避免继续发送过期内容。
- Teams 分析和任务提醒尊重服务端完整冷却时间，最长 24 小时；长时间离线或冷却后从本轮完成时间重新计时，避免紧接着再提醒一次。
- 新报告保存任务输入指纹。标题、要求、截止时间、分类、完成状态或模型变化后，旧建议不再作为当前建议展示；旧报告和任务不删除。没有指纹的历史报告等待重新分析，系统通知在实际发送前再次核对。
- 仅开启定时提醒时也有独立的 DeepSeek 密钥和模型入口。保留总览右侧宽版面板、1～10 小时间隔、关闭开关、「立即分析」和小三角完整折叠；折叠不改变开关或间隔。

## 升级与数据保护

已有旧普通版或主题版，请打开通用补丁 DMG，双击「CampusDesk 更新补丁.app」，核对原应用后安装；也可解压补丁 ZIP 后运行，无需卸载旧版。

- 保持所选版本的应用路径、应用标识、资料目录和钥匙串命名空间，两版数据不合并。
- 正常退出所选应用后，先备份应用、学习资料、网页会话和偏好，逐项核验内容、权限与链接，再替换应用并复验。失败回退应用，不用旧资料覆盖用户目录。
- 不清除登录或 API 密钥，保留现有个人任务、日程、完成标记、提醒开关和历史报告。早期版本缺少首次启动标记时，也不会因此重置登录。系统可能要求既有凭据访问授权，服务端令牌到期仍需正常重新授权。
- 成功后重新打开新版，更新器自动退出并移入废纸篓；可安全识别的独立补丁镜像会卸载并清理。ZIP 原文件、主程序和备份保留，失败时保留补丁。

完整行为和备份位置见 [升级补丁说明](https://github.com/xuanqiwang645/CampusDesk/blob/v2.0.1/Updater/README.md)。升级过程不改写受保护资料；新版重新打开后的正常同步和用户操作仍会保存新记录。
