保持 AI 任务提醒在「今日概览」右侧、面板样式按钮旁的位置。宽窗口中，边框向左延伸至可用空白，保留右侧锚点，让开关、间隔、立即分析和优先建议有更长的阅读空间。窄窗口继续自动换行，保留现有功能与配色。

## 更新与安装

准备两套 Apple Silicon 安装产物，最低 macOS 12：

- 原位更新补丁 DMG／ZIP：打开其中「CampusDesk 更新补丁.app」，核对原应用后安装。自动备份应用、学习资料和本机会话，校验密钥组件一致，只原位替换应用。
- 完整安装包 DMG／ZIP：用于首次安装，也可替换同一主题版应用。两套产物内的 Build 100 应用内容一致，各自附带 SHA-256 文件。

补丁会按文件内容、链接与权限核验受保护资料，校验失败时停止或原子回退应用，不把旧资料备份覆盖回当前资料。同一完整构建重复运行会直接提示。正常启动后的同步仍会产生新记录，服务端令牌的有效期不由补丁更改。

保留 Build 99 的 Teams 先分析后分类、1～10 小时任务提醒、总览建议与深色修正。此构建使用原应用标识及同一签名身份，未经过 Apple Developer ID 公证。
