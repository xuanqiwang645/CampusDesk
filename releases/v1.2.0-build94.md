# CampusDesk Theme Edition v1.2.0 Lagoon · Build 94

本次主题版更新汇总 v1.2.0 / Build 78 之后的改进，重点是完整显示当天课程、保护已有课表，以及让看板和后台同步更少打扰。应用版本仍为 **1.2.0**，构建号为 **94**，发布标签为 `v1.2.0-build94`。

## 主要更新

- **完整的今日课程**：卡片看板列出当天全部已读取课程，不再只显示前三节；新增「查看完整课表」，点击后回到本地今天。课程表跨午夜跟随本地日期，手动浏览的日期继续保留；上课时间仍按北京时间显示。
- **不完整读取保留已有课表**：希悦课程卡片缺少标题、时间或尚未加载完整时，本次读取不覆盖有效缓存，并提示等待后重试。确认完整的空白日期与空课表仍会正常更新。
- **更紧凑的看板**：标题改为「今日概览」，待办统计与两项 GPA 合并为一条摘要；GPA 区分学校值、分档参考与线性参考，缺少数据显示「—」。待办按来源和学科逐行排列，保留完成、关注、截止时间、添加和查看全部入口，中英文与窄窗口都使用同一层级。
- **原生玻璃按钮**：macOS 26 及以上使用系统工具栏展示成绩更新、专注和同步操作，学校网页窗口的操作按钮也采用系统玻璃样式。旧系统继续使用网页工具栏；页面内按钮保留键盘焦点、按下和禁用状态，并适配减少动态效果、减少透明度和高对比度。
- **更安静的浏览器同步**：Teams 定时同步复用已建立的专用标签，避免反复创建或选中标签、切换浏览器窗口。浏览器退出或专用标签缺失时暂停，主动登录和手动同步可重新建立所需标签。开发回归测试改用独立无头浏览器，避免测试启动桌面 Chrome。
- **保存与刷新优化**：减少保存时重复处理大型状态、课程倒计时的重复计算，以及未变化列表的重绘。待办跨过截止时间后会更新逾期分组；超限导入返回失败提示并恢复界面操作。

退出 CampusDesk 后，将 **CampusDesk Theme Edition.app** 放回原安装位置，替换同一主题版应用；如果原先位于 `~/Applications`，请仍放回该目录。应用标识和数据目录不变，正常替换不会清除登录、API 密钥或学习数据，建议更新前导出备份。公开安装包不附带个人数据、学校入口、登录会话或密钥。

应用使用本机持久签名，**未经 Apple Developer ID 公证**。首次打开请通过 macOS 自身的安全提示核对并确认信任，不要全局关闭 Gatekeeper。

## 使用边界

- 部分慢速加载或布局变化的希悦页面仍可能使单次同步失败，需要等待页面加载完成后重试。课程、截止时间和学校通知以原平台为准。
- Teams 后台读取仍需要浏览器可用、有效登录和自动化权限；不保证发现或读取账号的全部频道、聊天与历史消息。
- 原生玻璃外观随 macOS 版本与辅助功能设置变化。小组件刷新由 WidgetKit 调度，不能保证逐秒同步。
- 分档和线性 GPA 仍为参考估算；界面显示学校 GPA 时保留来源量表。待办勾选只保存在本机，不代表已向学校提交。

各阶段改动及验收范围见[开发历史](../docs/development-history.md)。
