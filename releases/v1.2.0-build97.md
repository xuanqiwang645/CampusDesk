# CampusDesk Theme Edition v1.2.0 Lagoon · Build 97

本次主题版更新汇总 Build 94 之后的改进，重点修复课表、表单和后台读取中的状态问题，并加入密码解锁的设置页彩蛋。应用版本仍为 **1.2.0**，构建号为 **97**，发布标签为 `v1.2.0-build97`。

## 主要更新

- **课表显示更准确**：修复跨午夜课程的倒计时、高亮和小组件结束时间；希悦课表容器仍在加载时保留上一份有效缓存，确认完整的空课表仍可正常更新。
- **填写内容更可靠**：临时调课的未保存字段不再被后台刷新清空；自编课程回车保存后正确清空输入，避免再次回车重复添加。
- **校历导入保护**：尚不支持的 ICS 持续时长、重复例外和取消通知会明确报错并保留原校历，避免生成错误的放假规则；较早 PDF 的延迟结果不能覆盖新选择或恢复后的备份。
- **平台读取修复**：ManageBac 带学期或视图参数的作业链接可正确识别；Teams 本地索引没有可读 EC 会话时继续检查可见页面。账号变化、登录失效或拒绝授权时停止本轮读取，不通过另一种认证方式重试被拒绝的附件。
- **Graph 登录恢复**：取消登录后正确结束请求和忙碌状态，保留已有凭据，后续登录与同步可以继续。
- **设置页彩蛋**：在「连接与设置」底部输入正确密码后显示致谢内容；支持「收起并锁定」，离开设置或进入专注模式自动锁定，重新打开应用默认隐藏。同页后台更新保留当前查看状态。

延续 Build 94 的完整今日课程、紧凑看板和原生玻璃工具栏。

适用于 Apple Silicon（M 系列芯片）Mac，最低 macOS 12；桌面小组件需要 macOS 14，原生玻璃工具栏需要 macOS 26 或更新版本。此安装包未完成 Intel 实机验收。

退出 CampusDesk 后，将 **CampusDesk Theme Edition.app** 放回原安装位置，替换同一主题版应用；如果原先位于 `~/Applications`，请仍放回该目录。应用标识和数据目录不变，正常替换不会清除登录、API 密钥或学习数据，建议更新前导出备份。公开安装包不附带个人数据、学校入口、登录会话或密钥。

应用使用本机持久签名，**未经 Apple Developer ID 公证**。首次打开请通过 macOS 自身的安全提示核对并确认信任，不要全局关闭 Gatekeeper。

## 验证范围

完整 macOS JavaScript 与浏览器套件 553 项通过、零跳过，包含实际构建的小组件启动入口；原生 13 组测试和 Windows 共享逻辑 9 项测试通过。应用与小组件均为 Build 97，构建及严格签名验证通过。本机已核对当天八节课程完整显示，设置页彩蛋默认锁定。Windows 检查仅覆盖共享逻辑，本次不发布 Windows 安装包。

## 使用边界

- 部分慢速加载或布局变化的学校页面仍可能需要等待加载完成后重试；课程、截止时间和学校通知以原平台为准。
- Teams 读取仍需要浏览器可用、有效登录和自动化权限；不保证发现或读取账号的全部频道、聊天与历史消息。
- 暂不支持的 ICS 属性会拒绝导入，不代表所有外部校历格式均可使用。
- 原生玻璃外观随 macOS 与辅助功能设置变化；小组件刷新由 WidgetKit 调度，不能保证逐秒同步。
