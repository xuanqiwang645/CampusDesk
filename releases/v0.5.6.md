# CampusDesk 0.5.6

## 本次更新

- 修复学期日期输入被后台同步刷新吞掉的问题；输入框切换、页面切换和同步更新时保留未保存草稿，点击保存后才应用。
- 学校网址改为可编辑配置：新用户可填写希悦和 ManageBac 学校首页，保存后即可登录；配置仅保存在本机，重启和升级后保留。
- 增加学校网址校验与保存失败提示，保留原有精确来源限制，不包含个人学校地址或学习数据。
- 新增学期 GPA 预测：使用 ManageBac 页面明确显示的成绩组成及百分比权重，结合手动填写的学期日期估算。未评分部分按已评分组成均分延续，课程等权；不是学校官方 GPA，不保证最终成绩。

## 下载与安装

下载下方 **CampusDesk-0.5.6-macOS-arm64.zip**（Apple Silicon / M 系列 Mac，macOS 12 或更新版本），解压后退出旧版，将 CampusDesk.app 放入用户主目录的 Applications 文件夹并替换旧版。无需安装 Xcode 或编译工具。学习数据与学校配置独立存储，替换应用不会清除它们。

应用使用临时签名，**没有 Apple Developer ID 公证**。首次打开可能被 macOS 阻止；仅在确认信任本项目后，通过“系统设置 → 隐私与安全性”允许打开。不要关闭系统整体安全防护。
