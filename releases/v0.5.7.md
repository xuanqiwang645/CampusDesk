# CampusDesk 0.5.7

## 修复

- 补齐英文界面在成绩表、同步进度、K 线摘要、学校连接卡片和任务提示中的中文残留。
- ManageBac 成绩预测识别 Task Information 弹层中的 Task category averages 表：从 `Category (Weight)` 读取类别权重，从 `Mark (Score)` 读取百分比分数；未评分类别保留为空，不会把 Overall 行重复计入。
- 读取 Task Information 弹层时等待异步内容加载；表格只接受明确的类别、权重和成绩列，不将普通作业分数误当作类别成绩。

GPA 预测仍是估算：只使用账号可见且成功读取的类别权重与成绩；未评分部分按本课程已评分类别的加权均分延续。请以 ManageBac 和学校正式成绩为准。
