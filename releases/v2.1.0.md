# CampusDesk v2.1.0 · Build 106

- 内置 Liquid Glass 插件与 API 1 插件接口；macOS 26+ 使用 AppKit 原生玻璃，支持启停、0–100% 透明度、圆角及通透材质。文字与图表在独立前景层，保持清晰。旧系统及降低透明度模式保留现有显示。
- 主题版「AI 学习助手」新增 **ChatGPT / OpenAI API**。用户在软件设置中填写自己的 API Key，原生 helper 安全保存到当前版本的 macOS 钥匙串。支持模型列表、Responses API 流式回答、停止生成、恢复密钥访问与删除。ChatGPT 订阅与 API 用量分别计费。
- OpenAI 与 DeepSeek 密钥分离。请求只发送至所选供应商，OpenAI 不回退到其他供应商。发送范围沿用当前对话与用户勾选的学习资料；密钥不写入状态、备份、日志或插件接口。

DMG 和 ZIP 均提供；已有主题版请使用更新补丁，无需卸载。补丁更新前会备份应用和本机资料，保持原应用标识和资料目录。支持 Apple Silicon、macOS 12+；原生 Liquid Glass 需要 macOS 26+。

安装包采用本地证书签名，未经 Apple Developer ID 公证。首次打开可能需要在「系统设置 → 隐私与安全性」允许打开。发布包使用持久本机签名身份；升级后如已有凭据要求授权，请点击应用内「恢复密钥访问」，原钥匙串条目会保留。

所有 API 测试使用合成密钥及模拟网络，不附带个人密钥、学校配置、会话或学习资料。真实 OpenAI 调用由安装后填写的 API Key 和对应账户额度决定。
