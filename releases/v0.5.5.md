# CampusDesk 0.5.5

## 课表规则与成绩分布

- 自编课表支持每周课程和一次性课程。
- 支持单双周课程，并可设置单双周基准周（周一）。
- 支持节假日规则；设置后会隐藏当天常规课表和每周自编课程。
- 支持临时调课：取消原课程或在指定日期替换为新节次/新时刻。
- 保留数字 GPA，同时在成绩页显示百分制成绩分布饼图和百分比图例。
- 继续保留中文默认界面、English 切换、经典面板与卡片看板。

## 学习中心与界面

- 新增学习中心，汇总全局搜索、今日学习计划、同步可信度、变化收件箱、成绩目标模拟、EC 智能定位、附件中心和专注模式。
- 采用 Three.js、WebGL2 与 GLSL 分层渲染 Liquid Glass；内容层保持清晰，不参与折射。
- 优化页面切换和 Teams/EC 大量消息浏览，分批处理与分页展示，减少界面卡顿。
- 学校地址配置保存在用户本机的 Application Support 中，更新应用时保留；公开安装包不包含个人配置和学习数据。

## GPA 历史图

- 支持从 1 小时到 30 天的时间分度，保留收盘折线、K 线柱、成交量与 MACD 指标。
- 柱体标出数据；悬停时竖线跟随指针、横线吸附收盘折线并显示 GPA 数值，不显示日期标签。
- 保留红涨绿跌/绿涨红跌设置。图表仅展示本机已记录的 GPA 历史，不代表官方完整记录。

本版本提供 macOS arm64 压缩安装包，使用本机临时签名，未进行 Developer ID 公证。首次打开若被 macOS 阻止，请在系统设置中按需确认对该应用的信任。
