# CampusDesk v2.0.2 Tarantula · Build 105

2026-11-13 · Apple Silicon macOS 12 或更新版本。

为 Teams 的 DeepSeek 归纳加入强制限制，处理历史活动、普通邀请和重复抓取占据当前待办与小组件的问题。

## 归纳与本地复核

- 所有 AI 生成任务都复核原文学业行动，旧缓存也适用；选课、注册检查、行政通知和额外学分活动不能仅凭“homework”标签混入作业。正式学校作业和个人任务保留。
- 上课准备须有适用日期；today／tomorrow 只按原帖发表日推算。日期不明或超过 14 天且没有明确截止的旧内容暂存消息页核对，不能按抓取日滚动为当前任务；明确绝对日期的真正逾期作业继续保留。
- 增加“按新规则重审受限分析”入口，明确使用 API 额度；重审保留原文、任务标识及完成记录，不删除旧分析来强制重跑。
- 分析请求由软件提供当前时间及北京时间上下文，不能将新抓取的旧消息当作新活动，也不能补造缺失年份。
- 自动生成活动待办需要完整可核对的日期，以及引用原文的参加义务或已报名／确认参加证据。普通邀请和日期、义务不明的内容留在消息页核对。
- 原文证据、日期及参加依据均复核，长消息的分段归纳会保留参加依据。不满足规则的历史缓存也立即退出当前待办，无需重新调用 API。
- 已经过完北京时间活动日期的自动活动不进入当前待办、小组件或 AI 任务提醒。不会把尚未完成的逾期作业自动完成或删除；用户明确的人工分类和日期纠正优先。
- 对同一账号、相同原文、行动与参加依据和相同日期的重复自动任务合并展示，中英文 AI 标题不再阻碍去重。一个完成操作关联重复编号；原消息和完成记录保留。
- 设置页可查看「API 归纳限制」，消息页解释被限制的原因。小组件的跨年截止日期显示年份。
