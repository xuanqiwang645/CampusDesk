# CampusDesk Theme Edition v1.2.0 Lagoon · Build 98

新增跟随 macOS 自动切换深浅外观。应用版本保持 **1.2.0 Lagoon**，构建号为 **98**，发布标签为 `v1.2.0-build98`，保留 Build 97 的全部修复。

## 自动外观

在「连接与设置 → 面板样式 → 外观切换」选择「跟随 macOS 自动外观」。系统处于浅色时使用选定的白天配色，系统处于深色时使用「深夜」。自然绿、海湾蓝、暖阳橙均可作为白天配色；切回手动时恢复独立保存的手动主题。

- 页面、原生玻璃工具栏、GPA 图表与 WebGL 玻璃材质同步更新。
- 系统切换只更新配色，保留编辑文字、焦点、弹窗和图表视图，不把夜间外观保存成手动主题。
- 启动和页面重载前应用已保存的配色；唤醒和重新激活后再次核对系统外观。
- 修复深色模式中仍残留的亮色卡片、图表背景、预测表单及低对比文字。
- 旧版升级默认保持手动选择，已有配色与学习数据不变。

## 系统设置与切换时机

在 macOS「系统设置 → 外观」选择「自动」。macOS 会按 Night Shift 计划切换；没有该计划时按日出日落，并可能等待 Mac 闲置后切换。CampusDesk 跟随系统最终外观，不读取定位、不请求天气服务，也不更改系统设置。系统固定为浅色或深色时，应用跟随该固定外观。[Apple 外观说明](https://support.apple.com/en-bh/guide/mac-help/mchl52e1c2d2/mac)

适用于 Apple Silicon（M 系列芯片）Mac，最低 macOS 12；桌面小组件需要 macOS 14，原生玻璃工具栏需要 macOS 26 或更新版本。此安装包未完成 Intel 实机验收。

退出 CampusDesk 后，将 **CampusDesk Theme Edition.app** 放回原安装位置，替换同一主题版应用；如果原先位于 `~/Applications`，请仍放回该目录。应用标识和数据目录不变，正常替换不会清除登录、API 密钥或学习数据，建议更新前导出备份。公开安装包不附带个人数据、学校入口、登录会话或密钥。

应用使用本机持久签名，**未经 Apple Developer ID 公证**。首次打开请通过 macOS 自身的安全提示核对并确认信任，不要全局关闭 Gatekeeper。

## 验证范围

完整 macOS JavaScript 与浏览器套件 566 项通过、零跳过；原生 14 组测试通过，其中外观桥最终 37 项覆盖 AppKit KVO 到真实 WKWebView 的深浅事件、首屏和重载；Windows 共享逻辑 9 项通过。独立首帧复验 199 帧没有错误主题，自动切换保留输入焦点及未保存文字。DMG/ZIP 的解包内容与构建产物一致，严格签名及 SHA-256 校验通过。
