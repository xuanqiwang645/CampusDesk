# CampusDesk v2.0.0 Tarantula · Build 101

2026-11-13 · Apple Silicon macOS 12 或更新版本。

本次大版本完善总览 AI 任务提醒，并首次同时发布普通版、主题版完整安装包与兼容两版的通用升级补丁。

## 总览与学习任务

- AI 任务提醒保留标题右侧的位置，边框向左扩展至可用空白，开关、1～10 小时间隔与「立即分析」直接可见。
- 标题旁的小三角可完整折叠全部控制与建议，重新打开应用后记住折叠状态；折叠不关闭定时分析，也不修改原间隔。
- 保留 Teams 先经 DeepSeek 分析，再区分作业、活动与普通通知的流程；未分析、失败或待核对的通知不自动进入待办。保留人工纠错、全文分段和内容变化后重分析。
- 保留深色学习计划、表单、侧栏与提醒的可读性修正，以及跟随 macOS 自动切换深浅外观。

## 原位升级与数据保留

已有 CampusDesk 普通版或 Theme Edition，请打开通用补丁 DMG，双击「CampusDesk 更新补丁.app」，核对原应用后安装。也可解压补丁 ZIP 后运行。补丁不要求卸载旧版。

- 自动识别两版，保持原应用路径、应用标识、资料目录及各自钥匙串命名空间。普通版升级后也有新界面与 AI 功能；桌面小组件仍由主题版提供。
- 正常退出所选版本后，备份原应用、学习数据、网页会话和偏好等文件，按内容、权限和链接逐项核验。同盘原子交换应用后再次检查，失败回退应用；不把旧资料覆盖回用户目录。
- 保留早期内置学校入口与 Graph 公共客户端配置，明确本机设置优先。修复首次启动标记缺失时可能重置登录的历史逻辑。
- 支持早期临时签名及缺少稳定凭据组件的旧版；必要时 macOS 可能要求一次既有凭据访问授权。主题版当前稳定凭据组件保持逐字节一致。补丁不读取、清除或搬迁真实 API 密钥，服务端令牌到期仍需正常重新授权。
- 成功后自动打开新版，更新器自动退出并移入废纸篓；从独立补丁镜像运行时，会卸载并清理该 DMG。ZIP 解压运行仅清理更新器应用，原 ZIP 保留。主程序与备份保留，失败或无法安全识别来源时保留补丁。

完整说明及备份位置见 [升级补丁说明](../Updater/README.md)。重新打开后的正常同步与用户操作仍会写入新记录。
