## Build 98 跟随 macOS 自动外观（2026-11-12）

「连接与设置 → 面板样式」增加手动与跟随 macOS 两种外观模式。跟随系统时，浅色使用独立保存的白天配色，深色使用「深夜」；切回手动仍恢复原手动主题。旧版设置默认保持手动，不改变用户已有选择。

系统外观由 AppKit 的 `NSApplication.effectiveAppearance` 提供，与主窗口的手动外观隔离。页面、原生工具栏、GPA 图表和玻璃材质同步切换，系统事件只更新配色，不重建表单或保存成手动主题。启动、页面重新加载、唤醒和重新激活都会核对外观；首屏在页面主体渲染前应用已保存的选择。

本功能不读取定位、不请求天气服务，也不修改 macOS 设置。在 macOS 中选择「自动」后，应用跟随系统的日出日落或 Night Shift 计划；系统可能在设备闲置后切换，不承诺天文时刻立即切换。实际规则见 [Apple 外观说明](https://support.apple.com/en-bh/guide/mac-help/mchl52e1c2d2/mac)。


验证：完整 macOS JavaScript 与浏览器套件 566 项通过、零跳过；原生 14 组测试通过，其中外观桥最终 37 项覆盖 AppKit KVO 到真实 WKWebView 的深浅事件、首屏和重载；Windows 共享逻辑 9 项通过。独立首帧复验 199 帧没有错误主题，自动切换保留输入焦点及未保存文字。DMG/ZIP 的解包内容与构建产物一致，严格签名及 SHA-256 校验通过。 本机已备份 Build 97 及数据，安装并重新打开 Build 98，确认「跟随 macOS 自动外观」已保存。
