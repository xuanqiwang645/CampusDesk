## Build 71 修复与验收

- 系统日志记录桌面卡片添加成功；用户于 2026-10-14 明确确认“已出现，点击能打开行事历”。

## Build 72 小组件排版

- 今日安排：时间和事件类别放在左列，标题与地点放在右列；小、中、大尺寸分别保留两、三、五项，底部提示其余项目数。
- 截止提醒：小尺寸突出最近一项，中尺寸并列两张卡片，大尺寸显示四行。各尺寸均分开展示截止日期、紧迫度标签、剩余时间和截止紧迫度条。
- 下一节课：小尺寸给双行课程标题与倒计时预留空间；中尺寸将倒计时及下一节课放进独立区域。正在上课时，小尺寸标题同步显示状态。
- 图库使用合成日程展示真实排版，并在底部注明“示例”；真实摘要读取、课程筛选和点击链接保持已有行为。
- 43 张合成排版样例覆盖浅色/深色、长标题与长地点、五行密集课程、逾期、空日程、缓存过期及读取失败；人工检查关键样例无重叠。
- 20 项行事历、包标识和实际 Mach-O 入口回归检查通过，主题版构建与签名验证通过。
- Build 72 已替换到原主题版安装位置，应用启动及行事历摘要刷新已确认。沿用原持久签名，凭据辅助程序与更新前逐字节一致；旧应用和应用数据另存恢复备份。

## Build 73 小组件内容完整性

- 总览的小／中号各显示每类一项，大号每类最多两项，保留更多项目数量。既有 `CampusDesk.Today` 标识保留，已添加的小组件可直接使用新布局。
- 课程选择扩展到后续日期；日历独立显示校历与个人行事历，过滤已结束的事件。
- 所有未完成作业进入摘要候选；无日期任务显示“截止待确认”，远期任务不再被七天窗口过滤。超过 100 项时按类别分配，保留最近 20 项历史逾期任务的既有上限。
- 任务点击通过严格的 `campusdesk-theme://tasks` 路由进入待办事项，日历日期路由保持兼容。摘要仍只有显示字段，不包含原始来源地址或凭据。
- 原生摘要测试 42 项通过；行事历数据测试 17 项通过；49 张合成排版图覆盖三类同屏、浅／深色、长标题和仅有无日期任务的情况，关键布局已检查。
- 本机状态只读核对确认，新摘要包含当前全部未完成作业；这不代表学校平台上尚未同步的数据已被读取。
